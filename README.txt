CARA PAKAI:
1. Masukkan 9 foto kalian ke folder assets dan beri nama sesuai daftar di atas.
2. Masukkan file audio "sempurna.mp3" ke folder assets. Gunakan file audio yang kamu punya/hak aksesnya sendiri.
3. Buka index.html di browser.

GITHUB PAGES:
- Upload semua file/folder ke repository GitHub.
- Pastikan index.html berada di root repository.
- Settings > Pages > Deploy from branch > pilih branch utama dan folder /root.

CATATAN:
- Tombol musik sengaja tidak autoplay karena browser modern sering memblokir autoplay audio.
- Klik "Musik Off" untuk mulai memutar musik setelah file mp3 tersedia.
